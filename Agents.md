# Agent Working Rules

Before major changes, read `PRD.md`, `Architecture-essential.md`, `Agents.md`, `Claude.md`, and `docs/DATABASE.md`.

Required workflow: **INSPECT → PLAN → MODIFY → TEST → VERIFY → DOCUMENT**

- Inspect existing code and database structure before editing.
- Search before creating files, functions, routes, tables, or components.
- Never randomly rewrite working code or recreate the database.
- Never delete features, records, migrations, or user data without permission.
- Modify only files needed for the request; leave unrelated modules unchanged.
- Preserve OpenAPI-first contracts and regenerate clients after contract changes.
- Run proportional type, build, migration, and behavior checks.
- Fix introduced errors before continuing.
- Protect secrets, session data, personal data, and database backups.
- Record durable architecture or operating changes in the relevant project document.
