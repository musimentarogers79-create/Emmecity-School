---
name: Individual term fees
description: How pupil-specific saved term fees relate to shared academic fee schedules.
---

Treat each pupil's saved term fee as an individual price, not a common class, stream, or enrollment-type rate. When an administrator explicitly chooses existing pupil prices for a term, preserve each active pupil's exact amount as an individual "Term fee" charge and keep sponsored pupils at zero. Never replace varying pupil amounts with an average, median, or mode.

**Why:** Existing non-sponsored term-fee values vary within the same class/stream/enrollment-type groups, and there is no authoritative shared-rate table. The group schedule model cannot represent those individual values without changing them.

**How to apply:** Use approved shared fee schedules when available. If an administrator directs reuse of saved pupil prices, charge each pupil from their own saved value without inferring group rates.
